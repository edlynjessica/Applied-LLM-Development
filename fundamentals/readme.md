# 📘 Fundamentals

Before learning LangChain and building LLM applications, it's important to understand the evolution of Artificial Intelligence and how these concepts are connected.

## 🌳 Evolution of AI

```text
Artificial Intelligence (AI)
│
└── Machine Learning (ML)
      │
      └── Deep Learning (DL)
            │
            └── Generative AI
                  │
                  ├── Large Language Models (LLMs)
                  │
                  └── Agentic AI
```

---

# 🤖 What is Artificial Intelligence (AI)?

### Definition

Artificial Intelligence (AI) is a branch of computer science that enables machines to perform tasks that normally require human intelligence, such as learning, reasoning, problem-solving, understanding language, and making decisions.

### Real-Life Example

- Siri and Google Assistant
- Face Unlock on smartphones
- Self-driving cars
- Chess-playing computers

### Interview Answer

> Artificial Intelligence is the simulation of human intelligence in machines, allowing them to perform tasks like learning, reasoning, decision-making, and problem-solving.

---

# 🧠 What is Machine Learning (ML)?

### Definition

Machine Learning is a subset of AI where computers learn patterns from data instead of being explicitly programmed for every task.

Instead of writing rules manually, we provide data, and the model learns the rules on its own.

### Real-Life Example

Spam email detection.

Instead of manually writing thousands of spam rules, the model learns from thousands of spam and non-spam emails.

### Interview Answer

> Machine Learning is a subset of AI that enables computers to learn from data and improve their performance without being explicitly programmed.

---

# 🕸️ What is Deep Learning (DL)?

### Definition

Deep Learning is a subset of Machine Learning that uses Artificial Neural Networks with multiple layers to learn complex patterns from large amounts of data.

It performs exceptionally well on images, speech, videos, and natural language.

### Real-Life Example

- Face Recognition
- Speech-to-Text
- Medical image analysis
- Self-driving car vision

### Interview Answer

> Deep Learning is a subset of Machine Learning that uses multi-layer neural networks to automatically learn complex features from large datasets.

---

# ✨ What is Generative AI?

### Definition

Generative AI is a type of AI that creates new content instead of only analyzing existing data.

It can generate text, images, videos, music, code, and more.

### Real-Life Example

- ChatGPT writing an email
- GitHub Copilot generating code
- AI image generators creating artwork
- AI music generation

### Interview Answer

> Generative AI is a branch of AI that creates new content such as text, images, audio, videos, and code by learning patterns from existing data.

---

# 💬 What is a Large Language Model (LLM)?

### Definition

A Large Language Model (LLM) is a Generative AI model trained on massive amounts of text data to understand and generate human-like language.

LLMs can answer questions, summarize documents, translate languages, generate code, and hold conversations.

### Real-Life Example

- ChatGPT
- Gemini
- Claude
- GitHub Copilot

### Interview Answer

> A Large Language Model (LLM) is a Generative AI model trained on vast amounts of text data to understand, process, and generate human-like language.

---

# 🤖 What is Agentic AI?

### Definition

Agentic AI refers to AI systems that can independently plan, reason, make decisions, and use external tools to accomplish a goal.

Unlike traditional chatbots that only respond to prompts, AI agents can perform multiple actions with minimal human intervention.

### Real-Life Example

Suppose you ask:

> "Book me the cheapest flight to Delhi next Friday and email me the itinerary."

An AI Agent can:

- Search flight websites
- Compare prices
- Book the ticket
- Save the confirmation
- Send the email

without requiring separate instructions for each step.

### Interview Answer

> Agentic AI refers to AI systems that can autonomously plan tasks, make decisions, and use external tools or APIs to accomplish complex goals.

---

# 🔑 Key Takeaways

- AI is the broad field of making machines intelligent.
- ML is a subset of AI that learns from data.
- DL is a subset of ML that uses neural networks.
- Generative AI creates new content.
- LLMs are Generative AI models specialized in understanding and generating language.
- Agentic AI extends LLMs by enabling them to plan, reason, and take actions using external tools.
